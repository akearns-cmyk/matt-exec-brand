# Talk Abstract — Layer 4 Skill

> **Purpose:** Write a compelling talk abstract for conference submissions, event invitations, or speaker profiles.
> Abstracts are sales documents. They sell the talk to the organizer AND to the attendee scanning the schedule.
>
> **Depends on:** `foundation/point-of-view.md`, `foundation/audience-delight.md`, `foundation/creator-style.md`
> **Typically follows:** A developed POV or framework from `insight-extractor.md`

---

## When to Use This

- Matt is submitting to a conference CFP (Call for Proposals)
- An event organizer asked for an abstract or topic description
- Building a speaker one-sheet or profile page
- Proposing a keynote or workshop to a specific organization

## Abstract Structure Rules

### For event organizers (the submission abstract)
- Written in **third person**
- Stakes in sentence 1 — why this matters *now*
- The talk's argument in sentence 2–3
- What the audience will leave with (specific, not vague)
- Matt's credibility signal (one sentence — specific, not a resume recitation)
- Length: 150–250 words

### For attendee-facing program descriptions
- Written in **second person** ("You'll...")
- Problem the attendee has right now in sentence 1
- Promise of the talk in sentence 2
- 3 specific takeaways (not "frameworks" — actual things they'll be able to do)
- Length: 100–175 words

### For speaker profile / one-sheet
- Third person
- One tight paragraph (80–120 words)
- Lead with the *type* of thinking Matt brings, not his job titles
- One specific proof point (a result, a company, a named situation)

| The Question | "What Would You Do If You Knew the Meeting Wouldn't Help?" |

## Claude Instructions

### Step 1 — Sharpen the argument
Before writing, restate Matt's core argument in one sentence. If it's vague, stop and sharpen it. A weak argument produces a weak abstract, no matter how well-written.

### Step 2 — Write three versions

**Version 1: Submission abstract** (organizer-facing, 3rd person, 150–250 words)
**Version 2: Program description** (attendee-facing, 2nd person, 100–175 words)
**Version 3: One-liner** (for schedules, event apps, social promotion — max 40 words)

### Step 3 — Title options
Generate 4–5 title options using the formats above. Label each format type.

### Step 4 — POV alignment check
Confirm: Does the abstract accurately represent Matt's POV pillars from `point-of-view.md`? Flag any drift.

### Step 5 — Audience fit check
Does the abstract speak to the fears and hungers in `audience-delight.md` for this specific event audience? If the event audience differs from Matt's primary audience, note the adjustments made.
