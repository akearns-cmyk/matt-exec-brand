# Style Guide — Full Reference

> The complete grammar, punctuation, formatting, and language rules for all Matt Smith communications.
> `foundation/creator-style.md` contains the quick-reference summary. This file is the full rulebook.
> Load this file when a detailed style check is needed or when drafting longer-form content.

## English Variant

**Australian English throughout — no exceptions.**

Common differences to watch:

| Australian | US (do not use) |
|---|---|
| realise, recognise | realize, recognize |
| colour, behaviour, honour | color, behavior, honor |
| programme (noun) | program |
| licence (noun) / license (verb) | license (both) |
| organisation, mobilisation | organization, mobilization |
| ageing | aging |
| travelled, cancelled | traveled, canceled |

## Punctuation Rules

**Dashes:**
- Use hyphens only ( - )
- No en dashes ( – ) — not in any context
- No em dashes ( — ) — not in any context
- To create a pause or aside, use a comma or restructure the sentence

**Commas:**
- Oxford comma: use it in lists of three or more items
- Do not use commas as a substitute for clear sentence structure

**Apostrophes:**
- Possessive: Matt's, MyPass's, the team's
- Contractions: it's, don't, we're — acceptable in most contexts except formal documents

**Ellipses:**
- Avoid in professional communications
- Acceptable rarely in informal internal messages to signal an open thought

**Exclamation marks:**
- Avoid in external and thought leadership content
- One per internal message at most — only when genuine

**Quotation marks:**
- Double quotes for direct speech and quoted material
- Single quotes only within an existing double-quoted passage

## Forbidden Words and Phrases

These are banned across all content types:

**AI/tech buzzwords:**
- leverage (as a verb)
- synergy / synergies
- ecosystem (when used abstractly)
- game-changer / game-changing
- revolutionising / revolutionary
- journey (when used metaphorically about a company or project)
- passionate (as a descriptor for Matt or MyPass)
- thought leader / thought leadership
- innovative / innovation (unless describing a specific named thing)
- seamless
- robust (as a filler adjective)
- scalable (without a specific meaning attached)
- best-in-class
- cutting-edge
- world-class

**Opener prohibitions:**
- Never open an email with "Follow up" or any variation ("Just following up", "Following on from", etc.)
- Never open with "I hope this finds you well" or variants
- Never open LinkedIn posts with "I" as the first word
- Never open content with "In today's fast-paced world..."
- Never use "Thrilled to announce" or "Excited to share" as openers

**Structural prohibitions:**
- Never use "Why this matters" as a header or section label
- Never use the construction "It's not X, it's Y" — Matt rejects this framing
- Never use "At the end of the day..."
- Never use "Thoughts?" as a CTA (on LinkedIn or elsewhere)
- Never end with three rhetorical questions in a row
- Never use "This is so important" or "This changed everything"

**Tone prohibitions:**
- No manufactured urgency or sales pressure language in prospect comms
- No "Don't miss out" / FOMO framing
- No generic enthusiasm that doesn't earn its place

## Voice Rules

**Active over passive:**
> "We verified 130,000 worker credentials" not "130,000 credentials have been verified"

**Concrete over abstract:**
> "A shutdown mobilisation failure costs $2M per day" not "delays are costly"

**Specific over general:**
> "BHP's WA iron ore operations" not "a major mining company"

**Short sentences over long:**
- Target: 15–20 words per sentence average
- Maximum: 35 words before breaking into two sentences
- One idea per sentence in high-stakes communications

## Formatting Rules

**Emails:**
- Short paragraphs: 1–3 sentences
- Bullets only when genuinely listing distinct items — not to break up prose
- No over-formatting (no bold headers in casual emails)
- Subject lines: specific and functional, not clickbait
- Signatures: vary by context (see `references/email-examples.md`)

**LinkedIn posts:**
- No markdown headers inside posts
- No bullet lists in the first 3 paragraphs
- Hashtags: 0–3, at the end only, functional not decorative
- See `references/linkedin-style.md` for full LinkedIn rules

**Documents and longer content:**
- Headers for navigation, not decoration
- No more than 3 levels of hierarchy (H1 / H2 / H3)
- Tables for comparisons; not for information that reads fine as prose

## Length Calibration

| Content type | Target length | Rule |
|---|---|---|
| Internal email | 2–5 sentences | Ruthlessly short. If it needs more, it needs a meeting. |
| Cold outreach email | 3–6 sentences | Shorter is more effective. |
| Post-meeting follow-up | 4–8 sentences | Summarise their words back; add one value item. |
| External partner email | Cut first draft by 30% | First instinct is always too long. |
| CEO Weekly Update | 600–900 words total | Structured — see `references/ceo-weekly-email.md`. |
| LinkedIn post (short) | 150–250 words | Insight or observation. |
| LinkedIn post (medium) | 300–450 words | Story with lesson or framework. |
| LinkedIn post (long) | 500–700 words | High-value framework only — earn the length. |
| Newsletter | 400–800 words | One through-line. Not two. |
