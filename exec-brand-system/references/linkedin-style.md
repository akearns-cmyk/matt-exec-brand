## What LinkedIn Is For

LinkedIn is Matt's highest-leverage public channel. It reaches:
- Tier-1 operator HSE and operations leaders (primary buyers)
- Enterprise service provider GMs and MDs (secondary buyers / champions)
- Industry peers, regulators, and media (reputation amplifiers)
- Future talent and partners (long-term brand builders)

Every post should serve at least one of these audiences. If it serves none of them, it belongs somewhere else.

---

## The One Rule That Overrides Everything

**If a stranger could have written it, it isn't done.**

Every post must have at least one of:
- A specific data point from the MyPass platform
- A named industry situation (even if anonymised)
- A contrarian position Matt has actually defended
- An operational detail that only someone who's been on site would know

## Post Structure

### Line 1 — The Hook
- Must work before the "...see more" cutoff (roughly 200 characters)
- Must not open with "I" as the first word
- Must create enough tension or curiosity to earn the click
- See `skills/layer-3/hook-creator.md` for the 6 hook types

### Lines 2–4 — White space then body opens
- One blank line after the hook
- First body paragraph: the setup or tension
- Keep to 1–3 sentences per paragraph
- Maximum 3 lines of text before a line break

### Body
- Develops the single insight — not two insights
- If using a list: max 5 items, each specific and non-obvious
- No bullet lists in the first 3 paragraphs
- Lists come after the insight has been set up, not instead of setting it up

### Close
- One thing: either a question, an action, or a landing statement
- Not all three
- If a question: make it genuinely interesting to answer — not "Thoughts?"
- Landing statements often outperform questions for Matt's audience (they're busy; they want resolution, not another open loop)

### Hashtags
- 0–3 maximum
- At the very end only
- Only if they're genuinely useful categories (not decoration)
- Suggested: #WorkforceCompliance #Mining #SafetyLeadership — only when directly relevant

---

## Formatting Rules

**Do:**
- Short paragraphs (1–3 sentences)
- Line breaks between every paragraph
- Numbers when they're real platform data
- Em dashes only — wait, no. Per style guide: hyphens only, no em dashes
- Periods to end sentences

**Do not:**
- Use markdown headers (##, **bold header**) inside the post body
- Use exclamation points in serious content
- Reference carousel mechanics in text posts ("swipe left", "slide 3")
- Use all-caps for emphasis
- Use emoji as bullets or decoration (only if genuinely natural to the tone)

---

## Prohibited Constructions — LinkedIn Specific

- Do not open with "I" (algorithmic penalty + weak opener)
- Do not use "Thoughts?" as the CTA
- Do not end with 3 rhetorical questions in a row
- Do not write "This is so important" or "This changed everything"
- Do not use the vulnerability sandwich (humble opener - insight - humble closer)
- Do not open with a quote unless it's genuinely surprising
- Do not use "Here are X lessons I learned from Y" as the structure
- Do not pad with backstory that doesn't do work
- Do not tell the reader how to feel ("This is powerful", "Really think about this")
- Do not use filler transitions: "Additionally", "Furthermore", "In conclusion"

## Post Types and Cadence

| Post type | Frequency | Notes |
|---|---|---|
| Insight / observation | 2–3x per week | The workhorse. Sharp POV, specific detail. |
| Story with lesson | 1x per week | Needs a real story — not a parable. |
| Framework / named concept | 1–2x per month | Earn the length. Has to be a real framework. |
| Honest reflection | 1x per month | Costs Matt something to say. Not performance. |
| Contrarian take | 1x per month | Picks a side. Has the data to back it. |
| Announcement | Only when newsworthy | Not a cadence item. Only when something real happens. |

## The POV Pillar Requirement

Every post must connect to at least one pillar from `foundation/point-of-view.md`.

Before finalising, identify which pillar the post serves:
- Pillar 1: Worker-owned credentials as structural fix
- Pillar 2: Industry standardisation as network effect
- Pillar 3: Safety as systems-design problem, not rules problem
- Pillar 4: Compliance as revenue lever, not cost centre
- Pillar 5: Trust as structural, not relational

If a post doesn't connect to any pillar, it's either off-brand or a new pillar is emerging — flag it rather than publish it.

## The Delight Test — LinkedIn Version

Before publishing, ask: would a VP of HSE at a tier-1 mining operator:
- [ ] Stop scrolling for this?
- [ ] Feel like someone finally said what they've been thinking?
- [ ] Forward it to a peer with a specific comment?
- [ ] Trust Matt more after reading it than before?

If none of these, it needs another pass through `skills/layer-3/post-enricher.md`.

---

## Engagement Principles

- Reply to every substantive comment within 24 hours
- Replies should be as specific as the comment — not generic thanks
- If a comment raises a genuine point of disagreement, engage it directly
- Do not reply to trolls or bad-faith comments — silence is the correct response
- Reposts with commentary: only when Matt has a genuine addition to make
