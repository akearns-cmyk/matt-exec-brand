## How to Use This File

When drafting any email, load this file and identify the most similar example.
Use it to calibrate tone, length, and structure — not to copy content.

If no example matches the situation, flag it and ask Matt for one after drafting.
Over time, this file should grow into a library of 15–25 examples covering the full range of Matt's communication contexts.
